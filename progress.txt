## Codebase Patterns
- MapEditor is dev-gated via `process.env.NODE_ENV === 'production'` guard in constructor — same pattern as DebugMenu
- DOM overlays (banner, panel) append to `container.parentElement ?? document.body`; container is the canvas element
- SceneManager is abstracted behind a local `SceneManagerLike` interface in MapEditor.ts to avoid importing Three.js types and keep tests clean
- Test DOM mocks: use a `createdElements[]` queue (each `createElement` call returns a fresh MockEl) so banner (index 0) and panel (index 1) are independently testable
- For tests that need SceneManager, always use a SEPARATE container mock so event listener calls don't bleed between test setups
- `as any` is acceptable for internal interface mocks in tests (no eslint suppression needed — rule not configured for this pattern)
